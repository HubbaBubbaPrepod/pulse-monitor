# Changelog

## 0.4.0

- Go-агент Linux/Windows: CPU/RAM, процессы, диски, соединения, системные журналы,
  доступная GPU-телеметрия и опциональная выборка метаданных пакетов через TShark.
- POST `/api/agent/{id}/report`: токен узла в Bearer-заголовке, ограничение тела,
  валидация, идемпотентные повторы и автоматическое определение ОС.
- POST/DELETE `/api/servers/{id}/token`: выпуск, замена и отзыв токена владельцем.
  В хранилище остаётся SHA-256, исходный токен показывается только при выпуске.
- Снимки и серверы содержат source `demo`, `agent` или `waiting`; реальные снимки
  добавляют hardware, capabilities, временные метки samples.at и supported у GPU/дисков и dataSource у логов.
- История метрик, последние отчёты, события и отметки просмотра сохраняются на диске.
  GET `/api/events`, POST `/api/events/{id}/ack`, id `all` для общей отметки.
- Реальные статусы по heartbeat; события подключения, потери связи, нагрузки
  CPU/RAM/GPU и заполнения дисков. Интерфейс обновляет статусы и конфигурацию узлов.
- HTTPS для удалённого доступа, проверка публичного домена, службы Linux/Windows,
  сборки amd64/arm64 и инструкции backup/update в deployment/README.md.

## 0.3.0

- Страницы входа и регистрации владельца в обеих темах, GSAP-анимации, адаптивные формы, выход из аккаунта.
- Go-авторизация: bcrypt, сохраняемый владелец, cookie-сессии, CSRF и ограничение попыток; API мониторинга требует вход.
- Убран select-field сортировки процессов. GPU/VRAM добавлены в таблицу, сортировку, детали, CSV и конфигурацию узла.
- ОС не выбирается пользователем: новый сервер ждёт агента. API игнорирует присланные клиентом ОС, доступность и метрики.
- Новые auth-маршруты и изменения контракта описаны в README. Данные мониторинга остаются демонстрационными.

## 0.2.0

- Go API: реестр серверов, сохранение на диск, снимки, SSE, архив логов с фильтрацией и пагинацией.
- Режим реалтайма, сеть с деталями пакетов и соединениями, мониторинг дисков и GPU.
- Иконки ОС и процессов, сортировка процессов по памяти, архив прошлых запусков.
- Фронтенд подключён к API; при отсутствии бэкенда явно обозначает локальное демо.
- Контракты API и команды запуска описаны в README; агент и авторизация остаются следующим этапом.

## 0.1.0

- Первоначальный фронтенд Pulse Monitor: семь разделов, две темы, графики и управление демонстрационными серверами.
- Статическая сборка для самостоятельного размещения.
