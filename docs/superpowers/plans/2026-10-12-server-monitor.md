# Завершение мониторинга

Согласованный объём: действующий backend, постоянная история, события, HTTPS,
подключение узлов и в последнюю очередь Go-агент Linux/Windows. Сохранить Go 1.23,
монохромный интерфейс, существующую учётную запись и архив. gopsutil разрешён.

1. Проверить тестами токены, приём данных, дедупликацию и восстановление истории.
2. Реализовать хранение отчётов, статусы, события и HTTPS.
3. Подключить интерфейс к реальным данным и добавить управление токеном узла.
4. Создать агент: системные метрики, процессы, диски, соединения, доступные GPU,
   системные логи и опциональный захват метаданных пакетов через установленный TShark.
5. Проверить сбор на Windows, сборки Linux, полный цикл и перезапуск.
6. Подготовить инструкции запуска, службы, развёртывания и резервного копирования.

Пакеты и GPU показывать только при наличии соответствующих возможностей на узле.
Не подменять реальные данные демонстрационными. Изменения API описать в changelog.
