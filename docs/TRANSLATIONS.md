# Переводы

Словари интерфейса находятся в `lib/locales/ru.json` и `lib/locales/en.json`. Ключи сейчас представлены исходными русскими строками. `lib/i18n.ts` выбирает словарь, подставляет `{p0}` и другие параметры; при отсутствии перевода использует русскую строку или ключ. Сообщения удалённых журналов сохраняют исходный текст.

Для исправления перевода обновите значение существующего ключа, сохраните все placeholders и отправьте PR с контекстом экрана. Для новой UI-строки добавьте ключ в оба словаря. Выполните `node --test lib/i18n.test.mjs`, `npm run lint` и `npm run typecheck`; вручную проверьте переключение языка и длинные строки на узком экране.

Для нового языка потребуется также расширить тип `Locale`, выбор языка в UI и допустимые значения настроек бэкенда. Один новый JSON-файл не включает язык автоматически. Имена узлов, журналы и данные модулей принадлежат источнику, а не словарю интерфейса.

Документация: русский `README.md` / английский `README.en.md`, русские `docs/*.md` / английские `docs/*.en.md`, английские файлы сообщества GitHub / русские `*.ru.md`. При изменении команд, ограничений или поведения обновляйте обе версии.
