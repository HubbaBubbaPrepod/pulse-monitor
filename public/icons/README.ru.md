# Иконки брендов

SVG-иконки взяты из [Simple Icons](https://github.com/simple-icons/simple-icons), лицензия CC0-1.0.

[Исходники](https://github.com/simple-icons/simple-icons/tree/develop/icons).

Иконки отображаются через CSS-маски в соответствии с монохромной темой. Названия брендов и знаки принадлежат их владельцам.
