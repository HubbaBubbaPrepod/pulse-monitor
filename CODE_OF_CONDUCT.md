# Code of conduct

Keep project discussions respectful and focused on the work. Welcome questions, explain disagreements with evidence, and accept constructive criticism. Harassment, threats, personal attacks, discriminatory language, and publishing another person's private information are not acceptable.

These rules apply to issues, pull requests, reviews, and other project spaces. Maintainers may remove inappropriate content or restrict participation to protect the community. They should apply the same rules to everyone and consider context.

For a conduct concern, use a contact method the repository owner publishes on their [GitHub profile](https://github.com/HubbaBubbaPrepod). Do not disclose private details in a public issue or assume GitHub Security reporting is a conduct-report channel. Vulnerability reports follow [SECURITY.md](SECURITY.md). No response deadline is promised.
