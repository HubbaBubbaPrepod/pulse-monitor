# Deploying Pulse Monitor

The dashboard and agent are distributed as independent applications.

- [Installation, owner registration, HTTPS, and automatic startup](../docs/INSTALL.en.md)
- [Data, backups, upgrades, removal, and troubleshooting](../docs/OPERATIONS.en.md)
- [Pulse Agent: installation and permissions](https://github.com/HubbaBubbaPrepod/pulse-agent/blob/main/README.en.md)

Installers use locally extracted archives. First register the owner on loopback in the data directory the service will use, then enable remote HTTPS. The installation guide explains migration from a manually started instance.
