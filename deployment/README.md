# Развёртывание Pulse Monitor

Панель и агент распространяются как независимые программы.

- [Установка, регистрация владельца, HTTPS и автозапуск](../docs/INSTALL.md)
- [Данные, backup, обновление, удаление и диагностика](../docs/OPERATIONS.md)
- [Pulse Agent: установка и права](https://github.com/HubbaBubbaPrepod/pulse-agent#службы)

Установщики используют локальные распакованные архивы. Сначала создайте владельца на loopback в том каталоге данных, который будет использовать служба, затем включайте удалённый HTTPS. Инструкции по переносу данных ручного запуска приведены в руководстве установки.
