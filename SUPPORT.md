# Support

Start with [installation](docs/INSTALL.en.md) and [troubleshooting](docs/OPERATIONS.en.md#troubleshooting). Search [existing issues](https://github.com/HubbaBubbaPrepod/pulse-monitor/issues) before opening a new report.

For bugs and usage questions, include Monitor/Agent/module versions, OS and architecture, installation method, expected and actual behavior, and minimal reproduction steps. Attach only redacted logs or synthetic examples. Remove tokens, passwords, TLS keys, private addresses, and user data from logs and screenshots.

Use the repository for the affected component: [Monitor](https://github.com/HubbaBubbaPrepod/pulse-monitor/issues), [Agent](https://github.com/HubbaBubbaPrepod/pulse-agent/issues), or [Docker module](https://github.com/HubbaBubbaPrepod/pulse-module-docker/issues). For an unclear cross-component issue, begin with Monitor and include all versions. Response times and fixes are not guaranteed. Report vulnerabilities privately using [SECURITY.md](SECURITY.md).
