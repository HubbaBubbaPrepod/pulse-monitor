# Правила поведения

Обсуждайте работу уважительно и по существу. Принимайте вопросы, обосновывайте разногласия фактами и учитывайте конструктивную критику. Недопустимы травля, угрозы, личные нападки, дискриминационные высказывания и публикация чужой приватной информации.

Правила действуют в Issues, PR, review и других пространствах проекта. Сопровождающие могут удалять недопустимые материалы или ограничивать участие для защиты сообщества. Они должны применять одинаковые правила ко всем и учитывать контекст.

При проблеме с поведением используйте способ связи, который владелец репозитория опубликовал в [профиле GitHub](https://github.com/HubbaBubbaPrepod). Не раскрывайте приватные подробности в публичном issue и не считайте GitHub Security каналом для сообщений о поведении. Уязвимости описаны в [SECURITY.ru.md](SECURITY.ru.md). Срок ответа не обещается.
