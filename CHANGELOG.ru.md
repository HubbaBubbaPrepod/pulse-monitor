# История изменений

## [0.7.0] — 2026-10-25

- Добавлен необязательный runtime `wasip1`: ограниченный WASI-интерпретатор, посредники разрешённых операций, согласование поддержки и отдельное состояние. Компоненты без runtime сохраняют нативное поведение.
- Секретные поля и настройки хоста не передаются гостю; смена runtime или контракта разрешений требует повторного согласия.

- Ограничено время чтения истории; добавлены наблюдение за WAL и быстрые последние логи без подсчёта архива.
- При отмене и завершении модуля останавливаются его группа процессов / Windows Job.
- Защищены HTML/API-ответы, проверяются адреса доверенных прокси, ограничена частота отчётов каждого узла.
- Windows-установка требует NTFS и использует Local Service с ограниченными правами.
- Сборка переведена на Go 1.27.3, Next.js обновлён до 16.4.2.

## [0.6.4] — 2026-10-19

- Таймаут записи события отключения узла больше не останавливает Monitor. Проверка повторяется без потери несохранённого события.
- Для тестов модулей используется небольшой нативный бинарник, чтобы проверки CI с детектором гонок укладывались в лимиты загрузки.

## [0.6.3] — 2026-10-18

- Количество процессов в обзоре подстраивается под высоту соседней карточки логов и заполняет доступное место.

## [0.6.2] — 2026-10-18

- Выровнена высота карточек процессов и логов в обзоре при расположении рядом.

## [0.6.1] — 2026-10-18

- Согласованы сетка последних логов и скрытие источника на узких экранах. Даты отображаются полностью; сгруппированный архив прокручивается на телефонах. Поведение бэкенда не менялось.

## [0.6.0] — 2026-10-18

- Обновление модулей через добровольно подключённый Marketplace и ручной JSON. Источник каталога привязан к издателю; совместимые настройки v2 сохраняются, изменение контракта требует нового согласия на права. При переходе v1 → v2 старый модуль отключается с сохранением бинарников и данных.
- Проверка предварительных версий включается отдельно; добавлены состояния установки и сравнение версий.
- Адрес узла необязателен и используется для справки. Агент подключается к Monitor сам; порт и сертификат на узле не нужны. Изменение адреса больше не отзывает токен.
- Исправлены ширина превью процессов и выравнивание строк архива логов.

## [Не выпущено]

- Контрольные суммы миграций совместимы с LF/CRLF; интерфейс настроек модулей отправляет только изменяемые поля конфигурации.

- Перенос телеметрии, логов, истории метрик и событий в SQLite WAL: возобновляемая миграция и согласованные резервные копии. Настройка хранения логов по серверам; при обновлении очистка выключена.

- Добавлены нативные компоненты v2 на Agent/Monitor: периодические и ручные вызовы,
  закрытые настройки и состояние, явные разрешения и постоянные операции без повтора неизвестного исхода.
- Добавлены настройки компонентов, действия таблиц и отдельные формы, логи выбранного объекта,
  ID контейнеров и стандартные графики. Сборщики и API v1 сохранены.
- Исправлены конфликты регистра и размера метаданных, сохранение секретности поля при обновлении,
  гонка установки из каталога и запуск Windows-бинарников компонентов Monitor.

- Добавлена проверка пакетов v2 для владельца: схема компонентов Agent/Monitor,
  шаблоны для авторов и API без установки или запуска кода. Совместимость сборщиков
  v1 сохранена; неподдерживаемая установка v2 возвращает явную ошибку.

- Добавлен добровольно подключаемый каталог модулей: сохранение адреса, поиск, платформы, выбор опубликованной версии и подтверждение доверия. Пакеты проверяются по SHA-256 и устанавливаются общим установщиком; ручной импорт JSON сохранён, замена установленного ID через каталог запрещена.

## [0.4.0] — первый публичный выпуск

### Добавлено

- Независимая панель самостоятельного размещения: один Go-бинарник обслуживает статический UI и API, готовые архивы Linux amd64/arm64 и Windows amd64.
- Реальные узлы через отдельный Pulse Agent: метрики, процессы, диски, GPU при поддержке, соединения, журналы и события. Пустая установка ожидает агентов.
- Первый владелец, bcrypt-хэш, cookie-сессии, CSRF, ограничение попыток входа и HTTPS для удалённого доступа.
- Сохраняемые данные, история метрик, архив журналов с фильтрами, группировкой и CSV; выбор интервала, реалтайм и пауза просмотра.
- Русский/английский UI, редактор оформления, пользовательские палитры, импорт/экспорт JSON, сохраняемые настройки владельца.
- Экспериментальные модули v1: JSON-пакет с нативными сборщиками, настройками и представлениями table/cards/chart/logs; Docker-модуль в отдельном репозитории pulse-module-docker.
- Установщики Linux/systemd и Windows, проверки сборки, документация и MIT-лицензия.

### Исправлено

- Выбранный сервер сохраняется после перезагрузки; убраны дублирующие ссылки модулей в sidebar.
- Настройки модуля нельзя сохранить до загрузки конфигурации выбранного узла; необязательные коллекции манифеста возвращаются массивами.
- Миграция демо-архива читает журналы потоком, сохраняет исходную копию и реальные ранее подключённые узлы.

### Примечания

- Совместимая пара первого публичного выпуска: Pulse Monitor v0.4.0 / Pulse Agent v0.4.0.
- До v1.0 будущая совместимость не гарантируется. Модули выполняются без песочницы с правами агента.
- GPU/пакеты зависят от ОС, драйвера и прав; архивы JSONL автоматически не очищаются.
- Прежние 0.1–0.3 обозначали внутренние этапы разработки, а не публичные релизы этих двух репозиториев.
