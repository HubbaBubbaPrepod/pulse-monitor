# Политика безопасности

## Версии и область

Сообщайте об уязвимостях текущего публичного выпуска Pulse Monitor или текущей ветки main. Панель и агент выпускаются независимо; укажите версии обоих и Docker-модуля, если он затронут. Проект не обещает срок поддержки или ответа.

## Приватные сообщения

Используйте [Report a vulnerability](https://github.com/HubbaBubbaPrepod/pulse-monitor/security/advisories/new). Укажите затронутые версии, условия, минимальный сценарий воспроизведения, ожидаемые последствия и возможное исправление. Используйте вымышленные данные. Не публикуйте детали уязвимости в Issues до оценки сообщения сопровождающими; не прикладывайте реальные токены, пароли, TLS-ключи, приватные адреса серверов, журналы или скриншоты пользователей.

Проблемы агента: [Pulse Agent Security](https://github.com/HubbaBubbaPrepod/pulse-agent/security/advisories/new); сборщика: [Pulse Module Docker Security](https://github.com/HubbaBubbaPrepod/pulse-module-docker/security/advisories/new). Если компонент неясен, опишите всю цепочку в сообщении для Monitor.

## Границы развёртывания

Создайте первого владельца на loopback в каталоге данных службы. Удалённый доступ требует доверенного HTTPS. Храните токены и закрытые ключи вне статического каталога `out`; ограничьте права файлов и защитите backup. Модули исполняют произвольный нативный код с правами агента без песочницы. Поля конфигурации password не являются зашифрованным хранилищем. Доступ к Docker socket может дать контроль над хостом. См. [установку](docs/INSTALL.md), [модули](docs/MODULES.md) и [эксплуатацию](docs/OPERATIONS.md).
